# MCP server exercises

Nothing here is written yet. This file is the plan, kept in the repo so the
gap is visible rather than implied by an empty directory.

The exercises are meant to build one MCP server in four steps, each step
running before the next one starts:

- **01-instructions** — write a basic MCP server in TypeScript, then register
  it in this repository's `.mcp.json`, and in the user directory if you want it
  everywhere.
- **02-basic-server** — make the connection real and expose a single tool.
- **03-server-with-prompts** — add shared prompts to that server.
- **04-server-with-resources** — add resources, so the server can hand back
  content and not only answers.

Until a step has a file beside this one, it has not been done.
